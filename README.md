# Python File Handling & Automation Project

## Overview
This project demonstrates Python file handling and automation operations such as reading, writing, renaming, moving, and deleting files using Python.

## Features
- Read text files
- Read CSV files
- Write data into files
- Rename files
- Move files to folders
- Delete files
- Exception handling using try-except

## Technologies Used
- Python
- OS Module
- Shutil Module

## Project Files
- main.py
- sample.txt
- sample.csv

## How to Run

1. Open terminal in VS Code
2. Run the following command:

```bash
python main.py
